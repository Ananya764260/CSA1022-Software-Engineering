# Personal Portfolio Website

A responsive one-page portfolio built with plain HTML and CSS. It introduces me, lists my skills and showcases selected projects.

## Features
- Responsive layout (works on phone, tablet and desktop)
- Sections: About, Skills, Projects, Contact
- No build tools or frameworks needed

## Project structure
```
portfolio-website/
├── index.html
├── css/style.css
├── .gitignore
└── README.md
```

## Run locally
```bash
git clone https://github.com/<username>/portfolio-website.git
cd portfolio-website
# open index.html in a browser, or serve it:
python3 -m http.server 8000      # http://localhost:8000
```
