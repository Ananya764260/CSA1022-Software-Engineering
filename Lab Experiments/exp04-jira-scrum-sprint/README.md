# Experiment 4 - Scrum Project in Jira (1-week Sprint)
**CO2** | Tool: Jira

## Steps
1. *Projects > Create project > Scrum* -> name `Library Management System`, key `LMS`.
2. Import `backlog.csv` or create the 7 stories by hand.
3. Prioritise the backlog by dragging (highest first); set story points.
4. *Create sprint* -> `LMS Sprint 1`, duration **1 week**, goal: *"Users can register, log in and search books."*
5. Drag the top 5 items into the sprint -> **Start sprint** -> screenshot the board (`screenshots/sprint-start.png`).
6. During the week move items To Do -> In Progress -> Done and log work.
7. **Complete sprint** -> screenshot the board (`screenshots/sprint-end.png`) and the Burndown report.

## Backlog
See [`backlog.csv`](backlog.csv). Sprint 1 scope = LMS-1 to LMS-5.
