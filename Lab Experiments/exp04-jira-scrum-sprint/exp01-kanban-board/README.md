# Experiment 1 - Kanban Board (Jira / Trello)
**CO1** | Tool: Trello (or Jira Kanban template)

## Aim
Visualise tasks on a Kanban board with To Do, In Progress and Done columns and simulate the workflow.

## Steps
1. Create a board named `Campus Library App - Kanban`.
2. Add three columns/lists: **To Do**, **In Progress**, **Done**.
3. Add the sample tasks from `tasks.csv` (can be imported into Jira via *System > External System Import > CSV*).
4. Simulate the workflow: drag tasks across the columns in the order listed under *Workflow simulation*.
5. Take a screenshot after each stage.

## Result
A Kanban board with six tasks was created and moved across all three columns, showing work-in-progress and flow.
