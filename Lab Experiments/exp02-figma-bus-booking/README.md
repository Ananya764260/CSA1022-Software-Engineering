# Experiment 2 - Bus Ticket Booking Prototype (Figma)
**CO1** | Tool: Figma

## Aim
Sketch a simple clickable prototype of a bus ticket booking system.

## Frames (mobile, 390 x 844)
| # | Frame | Key components |
|---|---|---|
| 1 | Home / Search | From, To, Date pickers, Passengers, **Search Buses** button |
| 2 | Bus List | Cards: operator, departure/arrival, duration, fare, seats left, filter chips |
| 3 | Seat Selection | Seat grid (available / selected / booked legend), fare summary, **Continue** |
| 4 | Passenger Details | Name, age, gender, phone, email |
| 5 | Payment | UPI / Card / Net banking options, **Pay Now** |
| 6 | Booking Confirmation | Ticket ID, QR code, journey summary, **Download Ticket** |

## Prototype flow (Prototype tab -> On click -> Navigate to)
`Home -> Bus List -> Seat Selection -> Passenger Details -> Payment -> Confirmation`

## Figma tips
- Use Auto Layout for cards and form fields; create a Component for the bus card and seat.
- Define colour styles (Primary `#1E5EFF`, Success `#16A34A`, Danger `#DC2626`, Neutral greys).
- Present with the Play button and copy the share link.
