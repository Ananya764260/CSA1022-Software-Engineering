# Experiment 5 - MoSCoW Prioritisation: Library Management System
**CO2** | Tool: Excel / Google Sheets

Deliverable: [`library_moscow.xlsx`](library_moscow.xlsx) - all 10 requirements scored on **impact** and **feasibility** (1-5), with category and justification.

| Category | Requirements |
|---|---|
| Must-Have | Search by title/author; Email overdue notifications |
| Should-Have | Online reservation; Monthly admin reports; Librarian dashboard |
| Could-Have | QR scanning; Reviews & ratings; Multi-language |
| Won't-Have (this release) | Chatbot; Mobile app |

Method: Priority Score = Impact x Feasibility. Must-Haves are the core functions the system cannot work without; Won't-Haves have low impact relative to cost and are deferred, not rejected.
